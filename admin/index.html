Как войти

Токен создаётся на github.com → Settings → Developer settings → Fine-grained tokens: выбрать репозиторий antonvincent288/zapashoda-site, права Contents: Read and write. Токен живёт до срока, указанного при создании. Токен не отправляется никуда, кроме api.github.com, и хранится в localStorage вашего браузера. Один токен — для всех вкладок.

Статьи и pain-гайды

Тело статьи (body_html) — HTML. Обязательная структура: начинается с <div class="art-body">, разделы — <h2 id="s1">Заголовок</h2>, s2, s3... Первый раздел обычно «Коротко» с абзацем, начинающимся с <b>Прямой ответ.</b> — именно его цитируют ИИ-поисковики. Внутри абзацев уместны обращения «вы». FAQ вводится построчно в формате «Вопрос? :: Ответ» (два двоеточия с пробелами). «Заголовки» — построчно «s1 :: Коротко». Поле og оставляйте пустым — единая фирменная карта подставится сама. Сохранение = один коммит в ветку astrowind-migration, сайт пересоберётся за 2–5 минут. Если соседний бот сейчас пишет в репо, кнопка сохранения подождёт — следуйте подсказке.

Карточки моделей

body_html карточки — большой монолитный HTML. Меняйте аккуратно или только заголовок/описание. Числа в факт-таблицу и блок «Реальные цифры из практики» лучше доверить конвейеру — они сверяются с форумными источниками. Удаление карточек запрещено.

Настройки

Вкладка «Настройки» пишет конфиг на ветку main — как и раньше. Баннер, Метрика, заголовок главной, телефон, бот заявок.
