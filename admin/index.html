Настройки сайта

После сохранения сайт пересоберётся автоматически за 1–2 минуты (GitHub Actions). Обновите страницу сайта с очисткой кэша (Ctrl+F5).

Справка

  • Токен создаётся на github.com → Settings → Developer settings → Fine-grained tokens.
  • Выберите репозиторий antonvincent288/zapashoda-site, права: Contents — Read and write.
  • Токен живёт до срока, указанного при создании.
  • Токен не отправляется никуда, кроме api.github.com, и хранится в localStorage вашего браузера.
