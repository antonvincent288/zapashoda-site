Карта

Зарядные станции рядом

Карта зарядной инфраструктуры: тайлы Яндекс.Карт, станции из открытой базы OpenStreetMap. Выберите город — покажем точки, сети, разъёмы и мощность (где указана в базе). Адреса — из разметки OpenStreetMap и обратного геокодирования по координатам (ближайший адрес — возможна неточность номера дома). Знаете станцию, которой нет на карте? Добавьте её в OpenStreetMap (openstreetmap.org) — она попадёт в нашу базу при следующем обновлении.

Станции в выбранном городе

Выберите город, чтобы увидеть список с адресами.

Как пользоваться картой

Каждая точка — зарядная станция. Клик по метке покажет название, адрес (если есть в базе) и разъёмы. Покрытие в мегаполисах хорошее, в малых городах — частичное; станцию можно добавить в OSM за пару минут.

База данных © участники OpenStreetMap (ODbL). Картографическая основа © Яндекс. База обновляется автоматически.
