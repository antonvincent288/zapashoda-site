Как зарядить Toyota bZ3X и bZ4X: какой разъём

bZ3X и bZ4X из Китая — GB/T; европейские bZ4X — Type 2/CCS2. Это самая частая ловушка при покупке: версии внешне идентичны. У нас есть подробный разбор с признаками версий.

На странице модели Toyota bZ3X — полный разбор: как отличить версии, что докупить для GB/T, ссылки на руководство пользователя (RU).

Типичные боли линейки: T1-03 Кросс-версии разъёмов; UN-01 медленная зарядка на морозе.

Частые вопросы

Какой разъём у Toyota bZ3X?

У машин китайского рынка — GB/T. Европейский bZ4X — Type 2/CCS2. Отличить можно по лючку и VIN — признаки версий в нашем разборе.

Нужен ли адаптер bZ3X?

Да: Type 2→GB/T для городских станций; при частых поездках на трассе — DC-адаптер CCS2→GB/T.

Есть ли мануал на русском?

Да, РЭ RU для bZ3X есть в нашей базе — на странице модели.
