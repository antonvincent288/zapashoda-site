Как зарядить Evolute i-Pro, i-Jet и другие: разъёмы Type 2

«Зарядка evolute» — 3 616 запр./мес при том, что официальный бюджетный сегмент. Машины собираются в Пролетарске с разъёмами Type 2 (AC) и CCS2 (DC) — вся российская станционная сеть работает с ними напрямую.

Evolute — один из немногих брендов, где аксессуары «как для обычных европейских машин»: кабель Type 2, портативка Type 2, настенная станция Type 2. Наш каталог теперь покрывает и эту линейку — см. подбор ниже.

Частые вопросы

Какой разъём у Evolute?

Type 2 (AC) и CCS2 (DC) — европейский стандарт, адаптеры не нужны.

Какая станция нужна Evolute i-Pro?

OBC 7 кВт (1 фаза): достаточно портативки Type 2 или настенной станции 7 кВт. Трёхфазная 22 кВт даст те же 7 кВт.

Evolute — официальная гарантия?

Да, бренд официальный: страховка и гарантийное обслуживание проще, чем у машин параллельного импорта.
