# Дорожная карта «Запас хода» (zapashoda-ev.ru)
_Собрал Алиса, 03.11.2026, по фактическому состоянию прода и памяти сессий. Всё, что касается денег, цен и публикации, подтверждает только владелец. Если факта нет в этом документе или в репо — не придумывать, спросить Алису через мост._

## Стратегия (решение владельца, зафиксировано 01.11)
Сайт + Telegram (@zapashoda_ev + Mini App @zapashoda_ev_bot) = агрегатор: весь трафик ведём на сайт и канал,
предлагаем товары и услуги, но сами НЕ продаём напрямую:
- заказы отдаём дилерам/автосервисам (pay-per-lead или комиссия 10–20%);
- тем же дилерам поставляем товар ОПТОМ (двойная монетизация: лид + маржа);
- база знаний — крючок: партнёрам бесплатно (под их брендом), остальным платно.
Наши реальные лиды: аксессуары (чек 5–30 тыс ₽) и установка зарядных станций (20–60 тыс ₽). Машины не продаём.

## Зачем всё это: три горизонта (согласовано с владельцем 03.11)
Проект = «пылесос для трафика» + монетизация + цель «проект про электромобили №1 в РФ».
Движок построен; узкое место сегодня — не код, а топливо: индексация и внешние сигналы.
**Воронка:** инфозапросы → сайт (356 страниц под боли) → доверие через базу знаний → конверсия
(ТГ-канал, заявки дилерам/сервисам, каталог, Mini App, цифровой гайд) → деньги (опт + лиды/комиссии).
Пылесос №2 — Telegram: 4 шортса/день + пост в канал + пересборка сайта каждые 3 ч. Плюс делимые
инструменты (калькулятор, OG-плашки) для естественного шаринга.

**Горизонт 1 — ближайшие 2–4 недели: замкнуть деньги и зажечь индексацию.**
1) Платёжный контур (владелец): GAS v11 → тест-оплата → PDF на Диск → боевой терминал.
2) Вебмастер + GSC, sitemap (владелец) — без этого трафик не пойдёт.
3) Контент-конвейер (архитектор): болевые до 900–1200 слов, «Коротко»-блоки; НЧ-запросы дают
   топ-10 за 2–6 недель даже молодому домену.
4) Первая монетизация: PDF-пакет под «опт + Mini App» (архитектор), рассылка дилерам, ТГ-посев.
5) Ссылочная масса: 10–20 внешних ссылок — иначе СЧ-запросы («сколько стоит зарядить», ~5 тыс/мес)
   не взять раньше 2–4 месяцев.

**Горизонт 2 — 1–2 месяца: сеть монетизации.**
Автосервисы-партнёры (пак + карточки на /services/), дилеры с Mini App — измеримый поток заявок
на каждые ~1000 посетителей. После живого теста GAS — рубрики канала («Бонус недели», «Разрушители
мифов») как социальное доказательство для менеджеров ОД. Карточки бизнеса 2ГИС/Яндекс (нужна учётка
владельца) — бесплатные витрины.

**Горизонт 3 — 3–6+ месяцев: «номер 1 по электромобилям».**
Полное покрытие темы: все модели (145+), все боли зарядки, карта по всей стране, живой форум,
бренд канала. Монетизация многослойная: опт + лиды/комиссии + цифровые продукты + позже реклама
и партнёрские программы (банки, страхование).

**Приоритет №1 на сейчас:** платёжный контур → индексация → контент/посев. Новые фичи — после того,
как первые три работают.

## Правила работы в этом репо (обязательные)
1. **Ни одного выдуманного факта**: бизнес-константы (цены, кэшбэки, тарифы, контакты СТО) — только в
   data/site_config.json или DATA в build.py; значения без источника не вписывать.
2. **Секреты не в репо и не в мосте** (PAT, токены ботов, ключи терминалов). Ключи терминалов — только в
   Script Properties GAS.
3. **Перед пушем — свежий HEAD** (агенты коммитят параллельно, гонки были). Пуш: git/blobs → git/trees с
   base_tree последнего коммита → git/commits → PATCH refs/heads/main. build.py валидировать py_compile,
   JS на страницах — esprima, затем локальная сборка python3 build.py <dir>.
4. Деплой: site.yml триггерится на push в main путями data/**, build.py, services.py, artv3.py, catalog.py,
   style.css. bridge/, reports/ — НЕ триггерят. gh-pages — собранная ветка (коммиты «deploy: <sha>»),
   main — исходники. Прод проверять после деплоя с ?r=N (CDN max-age=600).
5. Все проверки финального кода — по проду, не по локали.
