Открытые данные: зарядные станции России

Мы отдаём базу зарядных станций сайта как открытый файл: /charging/stations.json. Данные собраны из OpenStreetMap, файл — статический JSON, обновляется регулярно. Берите для ботов, чатов, приложений и исследований.

Формат

ПолеЧто содержит
updatedдата выгрузки (YYYY-MM-DD)
stations[].lat, lonкоординаты WGS-84
stations[].nназвание точки
stations[].opсеть/оператор (если указан в OSM)
stations[].pwмощность, кВт (если указана в OSM)
stations[].cчисло портов (если указано в OSM)
stations[].aадрес/комментарий (если есть)
stations[].sсписок разъёмов: type2, ccs2, chademo, gbt, yazaki, schuko и др.

Пример

curl -s https://zapashoda-ev.ru/charging/stations.json | head -c 400

Файл без ограничений на запросы (статический CDN GitHub Pages). Точка обновления данных — выгрузка из OSM.

Условия использования

Данные производны от OpenStreetMap — условия ODbL: указывайте «© OpenStreetMap contributors» при использовании. Ссылка на сайт приветствуется, но не обязательна.

Что строить на этих данных

  • боты и чаты «где зарядиться»;
  • карты для региональных сообществ;
  • аналитика плотности сети по регионам;
  • интеграция в приложения и навигацию.

Если построили что-то полезное — напишите в Telegram: расскажем о вашем проекте в новостях сайта.
