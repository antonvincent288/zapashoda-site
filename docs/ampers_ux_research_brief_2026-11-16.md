# БРИФ: СИСТЕМНЫЙ АУДИТ И РЕДИЗАЙН zapashoda-ev.ru ПО ЛУЧШИМ ПРАКТИКАМ
Для Ампера · подготовлено Алисой 16.11.2026 · статус: к запуску экспертизы

## 1. Цель
Провести сквозной аудит всех разделов сайта — от главной до последней страницы — и переработать их по самым сильным решениям мировой практики: лучшие исследования по маркетингу, копирайтингу, психологии поведения и дизайну + разбор топовых игроков отрасли. Результат: план внедрения с волнами, метриками и приоритетами. Не «перекрасить ради красоты», а собрать механики, которые двигают конверсию, доверие и SEO/AEO.

## 2. База исследований — обязательный минимум
Поведение и психология (уже частично вшиты в скилл site-behavior-psychology, здесь — полная карта):
- NN/g: F-паттерн сканирования (~79% сканируют, не читают), 10 usability-эвристик Нильсена, правило «выше складки» — что в зоне первого экрана.
- Baymard Institute: статистика брошенных корзин (~70%), карточки товаров, формы, checkout-паттерны.
- BJ Fogg Behavior Model: мотивация × способность × триггер — каждая кнопка/CTA проверяется этой моделью.
- Чалдини: 7 принципов убеждения (соц. доказательство, дефицит, авторитет...) — где у нас честные механики, где пусто.
- Kahneman/Tversky: неприятие потерь, эффект обрамления — формулировки офферов, «без якорей цены» (PRICES_ON=false — использовать «выгоду» вместо цены).
- Парадокс выбора (Iyengar/Lepper): каталог 154 моделей — не перегружаем; сортировки, фильтры-гиды, «подбор по сценариям».
- Закон Хика: меню, фильтры, шаги — сократить время решения.
Копирайтинг и контент:
- Direct-response рамки: PAS (проблема-усиление-решение), AIDA, 4Ps — для лендингов и pain-статей.
- UX Writing / Content Design (Sarah Richards): заголовок = суть, глагольные CTA, «вы»-голос (у нас директива), микрокопия форм.
- AEO/GEO: первый абзац = готовая цитата для ИИ-поисковиков; FAQ; schema.org; llms.txt (на проде).
Дизайн и вёрстка:
- WCAG-контраст (AA), типографический масштаб, 8-pt сетка, tap-targets ≥44px.
- Trust-паттерны: бейджи совместимости, подписи источников, KPI-чипы (стандарт design-helper), иконки-круги.
- Core Web Vitals (LCP/CLS/INP) — дизайн не должен ломать скорость.
Метрики и эксперименты:
- AARRR, North Star; тепловые карты Clarity/Вебизор — у нас уже есть: байесовские апдейты гипотез (внутренний скилл math-physics).
- Статистика A/B: минимальные выборки, не «смотреть и менять».

## 3. Бенчмарк игроков — что изучить
Глобальные:
- Tesla.com — минимализм карточек моделей, конфигуратор, «без шума».
- ChargePoint / Electrify America — продуктовые страницы ЭЗС, наивгация по сегментам (home/business/fleet).
- PlugShare — UX карты: фильтры, карточки станций, статус занятости (наш следующий шаг).
- EV Database (ev-database.org) — сравнение моделей, таблицы, фильтры: эталон данных.
- InsideEVs — контент-механики, заголовки, перелинковка.
RU-игроки:
- punkt-e.ru — уже разведаны: посадочники по разъёмам (/by-connector/), сегмент-лендинги, тариф простоя, зелёный тариф; аккуратно брать паттерны, не копировать контент.
- Дром/Авто.ру — карточки и каталог-паттерны RU-аудитории.
- Дилерские лендинги Zeekr/BYD в РФ — как продают «китайские EV» в России: офферы, трейд-ин, кредиты.
Китайские бренды (аудитория проекта): Zeekr/BYD/AITO официальные сайты — карточки, конфигураторы, зарядные экосистемы.

## 4. Карта разделов — что аудировать (страница-за-страницей)
1. Главная — первый экран, ценность за 5 сек, маршруты к 3 аудиториям (выбираю машину / только что купил / ветеран EV — по стратегии воронки).
2. Каталог и карточки моделей — фильтры (закон Хика), бейджи совместимости, фото (уже 129/154), таблицы разъёмов, «Коротко» — стандарт карточки.
3. Карта ЗУ /charging/ — Cockpit UI уже внедрён; далее: живой статус занятости (отдельный проект), посадочные городов (сделано 36 городов РФ), SEO/AEO.
4. Блог/гайды/pain-статьи — сканируемость (NN/g), врезки «Важно/Совет/Пример», чек-листы, перелинковка в каждом витке, иллюстрации YandexART OS + фото Commons.
5. B2B (/b2b/) — сегменты, лид-форма, PDF-пакет дилерам (готов), кейсы.
6. Партнёрам /partners/ + инфраструктура — 9 сегментов, «Как это работает» — усилить CTA и офферы.
7. Калькуляторы (cost/time), разъёмы (razemy), tools — микроконверсии: email-ловушки, PDF-магнит (готов: таблица разъёмов 145 моделей).
8. /about/, /services/, /shop/digital/ — доверие: реквизиты ИП, отзывы (реальные, не фейковые — ноль фейкового UGC).
9. Dzen/Telegram — единый голос, rich-формат, хэштег-стратегия (скилл telegram-growth-expert).

## 5. Процесс работы Ампера
Фаза 1 (экспертный аудит): по каждой странице — список находок по исследованиям из §2 + паттерны игроков из §3, каждая находка с ссылкой на источник и «где у нас».
Фаза 2 (синтез): приоритизация — impact × effort; 3 волны: (а) быстрые победы — копирайт, CTA-формулировки, микро-разметка; (б) средний срок — структура разделов, новые блоки; (в) стратегические — редизайн, дизайн-система (daisyUI-токены — ждут ключей владельца).
Фаза 3 (внедрение): правки в ветку, QA-конвейер (ежечасный смок 16 URL × 2 ширины), метрики до/после.

## 6. Ограничения (не нарушать)
- Палитра прода: оранжевый акцент #FF6F00 (градиент FF8F33→FF6F00 с тёмным текстом), синий #0161EF только в лого, циан #00E5FF — только инфослой.
- PRICES_ON=false: цены в каталоге только; «скоро» вместо цен, SKU сняты.
- Голос «вы», средняя длина предложения ~≤20 слов, заголовок = суть (humanization-waves).
- Фото: только Wikimedia Commons с допустимыми лицензиями + атрибуция; выставочные/шоурум приоритет; номера замазывать и перепроверять.
- Никакого фейкового UGC и накруток (Дзен/ТГ).
- Каждое внедрение — через quick-patch с RACE-check; конкурентные пуши отменяют деплои друг друга — дожимать workflow_dispatch.
