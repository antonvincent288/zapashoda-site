# Дизайн-рубрика «Запас хода» — единый язык визуальной приёмки

ЗАЧЕМ: «некрасиво» — невалидируемое замечание. ИИ-агенты не видят красоту, они видят свойства DOM/CSS.
Замечание фиксируется только в терминах измеримых свойств. Эта рубрика обязательна для всех агентов,
генерирующих или проверяющих визуал (D1 арт-директор, D2 Gamma-Pro, ревизор, сыщик).

## Формат замечания (единственный принимаемый)
```
СТРАНИЦА: /blog/slug/ (можно несколько)
ВЬЮПОРТ: 390px (или 1440px)
ЭЛЕМЕНТ: селектор или видимый текст («кнопка Подобрать комплект»)
СВОЙСТВО: что именно не так (см. словарь ниже)
ОЖИДАНИЕ: как должно быть (число/правило, не «красивее»)
СКРИНШОТ: если есть — прикладывать (сильнее 10 слов)
```
Пример ПЛОХО: «меню кривое».
Пример ХОРОШО: «шапка 390px: 11 ссылок в одну строку переносятся в 2 ряда, между
элементами нет группировки; ожидание — делить на группы с подписью (10px caps) и разделителем 1px».

## Словарь свойств (на что смотреть вместо «красиво»)
1. Типографика: font-size, font-weight, line-height (текст 1.6–1.75), letter-spacing заголовков (−0.02em),
   длина строки текста 60–75 знаков (max-width ~680px), иерархия H1>H2>H3 (размеры по сетке, а не на глаз).
2. Ритм отступов: кратность 8px; секции 56px (мобайл) / 68–80px (десктоп); внутри карточек 16–24px;
   между заголовком и текстом 8–14px; между блоками 24–40px.
3. Выравнивание: контент в .wrap 1152px по центру; тексты — по левому краю (никогда justify);
   вертикальное центрирование в hero/CTA; baseline-align в таблицах.
4. Контраст: текст 4.5:1 минимум (WCAG AA); кнопки: тёмный текст на светлом/белый на синем #0161EF; не серым на сером.
5. Мобильный: кнопки/ссылки-цели ≥44px; 0 горизонтального overflow; таблицы — обёртка со скроллом;
   иконки ≤24px; отступы от краёв 24px.
6. Повторяемость: одинаковые компоненты выглядят одинаково на всех страницах (карточки, чипы, кнопки, таблицы).
7. Иерархия внимания: на первом экране один главный CTA; вторичные — ghost; не более 2 уровней акцента.
8. Иконки: единый набор (stroke 2, 24px вьюбокс); эмодзи только как семантические маркеры, не как кнопки.

## Чек-лист приёмки визуала (прогонять по каждой новой странице/правке)
1. H1 один, размер по сетке clamp, letter-spacing −0.02em
2. Lead-абзацы ≤ 680px ширины, line-height 1.6–1.75
3. Все кнопки ≥44px высоты, единый радиус 11px, единые цвета (primary #0161EF / ghost)
4. Отступы секций: 56px моб / 68px десктоп; ничего не «слипается» и не «разъезжается»
5. Таблицы: зебра в обеих темах, hover, обёртка overflow-x на мобиле
6. Карточки: одинаковый padding/radius/тень во всех сетках (mgrid/bgrid/cards/duo)
7. Чипы выглядят кликабельными (бордюр + hover + стрелка/иконка)
8. Футер: группы 4 колонки, мобайл — стек, ссылки ≥44px цели
9. Меню: группы с подписью, разделители, B2B выделен pill
10. Тёмная тема: ни один текст не теряет контраст; zebra/hover переопределены
11. SVG/иконки: всегда заданы width/height (анти-паттерн «огромные иконки 342px»)
12. Изображения: object-fit contain/cover по месту, радиус 12–16px, lazy loading
13. Формы: инпуты 44px, focus-кольцо, placeholder без жирного
14. Не используется: gold/жёлтый (устаревшая палитра), bg-green-600 (легаси), zs-* старые классы вне legacy-стилей
15. КРИТИЧНО: КАЖДЫЙ контентный контейнер (.article, .sec > *, карточки) лежит ВНУТРИ .wrap —
    на 1440px проверять ВСЕ элементы, а не первый: x >= wrap.left + 24px, ширина <= wrap.width - 48px.
    Анти-пример (06.11, модели): body-блок рендерился вне wrap на x=0 вплотную к краю экрана —
    баг прошёл QA, потому что измеряли только первый .article. Прогон геометрии — по всем контейнерам.

## Правило владельца
Любое «некрасиво/кривое» от владельца агент обязан перевести в формат замечания выше,
если владелец не указал свойство сам — агент обязан предложить 2–3 кандидата-гипотезы и подтвердить.
