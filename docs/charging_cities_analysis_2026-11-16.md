# Анализ региональных страниц /charging/[city] — 16.11.2026

## Статус
- Все 36 посадочных отвечают 200, рендерятся с динамическими счётчиками станций из базы (пример: Москва — 318 точек, заголовок «Зарядные станции в Москва: 318 точек, бренды и разъёмы»).
- Sitemap содержит все 36 URL.
- Найден дефект: Реутов — 0 станций в базе при живой странице («0 точек»). Химки — 12.

## Спрос (Wordstat, 30 дней, фраза «зарядные станции»)
- Москва: 27 622 запроса; Санкт-Петербург: 9 036; Казань: 1 508.
- Фраза «зарядные станции для электромобилей»: 25 821 по РФ за 30 дней.
- Топ-3 города по спросу закрыты посадочными; компактные города (Иваново 30, Чебоксары 19, Владимир 21, Тула 20) — на порядки меньше по счётчику станций, но аффинити вне столиц выше среднего — локальный спрос недообслужен контентом.

## Рекомендации (нужны решения владельца)
1. Реутов: вшить блок «ближайшие станции» (радиус/Москва 318) или 301 → /charging/moskva/ пока счётчик 0. Пустая страница — минус для UX и SEO.
2. Расширить базу станций в городах с высокой аффинитностью (при следующем обновлении stations.json приоритизировать компактные города с низкой нормализованной мощностью станций).
3. Индексация посадочных — проверить в Я.Вебмастере после 2–4 недель (не проверяемо изнутри).
