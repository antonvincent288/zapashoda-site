Как читать матрицу

Китайские машины с портами GB/T заряжаются на китайских станциях напрямую, а для городских Type 2-станций нужен адаптер Type 2 → GB/T (22 кВт). Европейские машины — наоборот: городские станции напрямую, китайские станции через обратный адаптер. Американские и японские машины (Type 1 / CCS1) — через адаптер Type 1 → Type 2 для медленной зарядки; быстрые станции для них в России пока ограничены.
