# Роль: Model-fit-editor («какая станция нужна модели»)

Цель: на карточке каждой модели блок из 3 строк: Дом (OBC), Трасса (DC-потолок), Розетка 220 В (часы до 80%). Пилот: 5 моделей с уже проверенными разборами (Zeekr 7X, 001, 007, Denza D9, Geely EX5). Формулировка против переплаты: «Станция на 7 кВт даст тот же результат, что 22 кВт».
Данные: site/src/data/models_light.json (порт), models_battery.json (ёмкость), OBC/DC — только официальные спецификации; конф: verified | approx. Файл данных: site/src/data/models/charging_fit.json. Блок — шаблонный компонент, чтобы потом включить на всех 145 моделях. Не трогать цены (PRICES_ON=false — «скоро»).
