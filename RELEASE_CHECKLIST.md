# Конвейер правок zapashoda-ev (чтобы одно не ломало другое)

## Перед любым PUT
1. Перечитать sha файла с HEAD (`?ref=astrowind-migration`) — сосед коммитит параллельно.
2. Сверить прод с HEAD: если прод отстаёт — править только поверх HEAD.
3. Синтакс: .astro — баланс `<section>`/`</section>` и `<div`/`</div>`; .js — `pip install esprima` и parse.

## После правок
4. Один пакет = одна тема. Несколько файлов одной темы — одним пакетом коммитов, потом один деплой.
5. Дождаться зелёного build & deploy на ФИНАЛЬНОМ коммите (QA-fail на промежуточном — не приговор).
6. Прод-проверка: эмуляция (десктоп 1440 + мобильный 390), pageerror-коллектор, скрины. Не «на глаз».

## Синхронные бампы (иначе цикл авто-релоада)
- ZH_BUILD в site/public/dashboard.js
- ?v= в site/src/pages/charging/index.astro
- v в site/public/app-version.json

- Удалять запятые между объектами массивов ZH_SOURCES — SyntaxError убивает весь скрипт.
- Стирать чужие коммиты без diff-ревью (у второй сессии тоже задачи).
