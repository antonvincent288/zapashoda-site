## 2. Почему на нашей карте не все зарядки

Текущий `stations.json` собран из трёх источников: (1) datasets с раннего старта проекта, (2) боты соседа (авто-добавление), (3) ручные добавления. Источники **не сетевые**: мы не тянули данные напрямую из сетей (РусГидро API, Россети API, Энергия Москвы API, Rushyrd API). Именно поэтому:
- 1403 станции без бренда — «Зарядная станция» без оператора
- 88,8% без мощности — у нас нет данных по кВт
- Москва 291, СПб 89, МО 35 — «столичное» покрытие

## 3. Решения (по приоритету)

### Решение A (немедленное, бесплатно, без ключей): Overpass/OSM merge
OpenStreetMap — 1643 точки в РФ, у которых есть точные координаты, операторы (895 из 1643 с брендами/сетями) и разъёмы. Это **данных больше, чем у нас** (наши 1403 без бренда идут «как есть» с исходного датасета, OSM — с тегами). Можно:
1. Скачать Overpass-экспорт по России с фильтром `amenity=charging_station`
2. Смерджить с нашей базой: матч по координатам (±50 м) — новые точки добавляем, дубли — обновляем оператора/мощность/разъёмы из OSM-тегов
3. Запустить конвертер OSM-тегов в наш формат JSON (`socket:type2_combo` → CCS2, `socket:gb_dc` → GB/T DC, и т.д.)
4. Это даст +~600–1000 новых точек и заполнит pw/op для существующих

### Решение B (владелец): Яндекс Карты JS API + Places
Получить бесплатный API-ключ Яндекс.Карт (JS API + Геокодер, 25k запросов/сутки). Показывать карту Яндекс Карты на странице /charging/ через **Yandex Maps JS API 2.0 + сервис Яндекс Заправки** (они показывают статус зарядок live через свою инфраструктуру). Ключ нужен от владельца. Это закроет полный «Яндекс»-спрос без ручной работы.

### Решение C (владелец, долгосрок): партнёрство с Electro.cars или 2Chargers
Electro.cars — крупнейший коммерческий агрегатор РФ (170 000+ сессий/мес), показывает live-статус. 2Chargers — главное приложение сообщества. Партнёрство: белый лейбл или ссылка на их карту с нашей брендовой обёрткой — «полная карта + статус» без разработки API.

### Решение D (наша постоянная работа): объединение сетей вручную
Скрипт, который ходит по картам сетей (РусГидро API, Россети, Пункт Е, Electro.cars, Яндекс Заправки) и вливает новые точки в stations.json. Требует разработчика.

## 4. Тестирование текущей карты (жёсткий прогон)

1. Открываем /charging/ — рисуется Leaflet + кластеры + 2073 маркера. Лаг «пустых» точек: 88,8% без мощности — в попапе «Станция, адрес» без полезной информации. Поисковый запрос пользователя, скорее всего, не ответит: «где быстрая станция рядом с 150 кВт?»
2. Кластеры Leaflet: при зуме на Москву — десятки сгруппированных маркеров, раскрыть можно только поштучно. В реальной РФ >12000 станций — кластеризация Leaflet падает при >3000 маркеров (баг-тест не делался — риск).
3. Фильтр по разъёмам: работает по `s` полю, но у 1228 станций `s` — пустой массив. Фильтр их прячет молча — пользователь теряет станции без причины.
4. Сообщить статус станции в Telegram — ссылка работает.
5. Пустая точка без оператора и мощности — попап «Станция» — бессмысленный UX.
