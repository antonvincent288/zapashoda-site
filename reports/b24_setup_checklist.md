# Битрикс24: настройка за 10 минут (для владельца, Z-0033)

## Почему Битрикс24
Бесплатный тариф навсегда: 5 пользователей, воронки, лиды/сделки, мобильное приложение.
В бесплатном тарифе НЕТ: автоматизаций (роботы), телефонии, больших дисков — нам не нужно.

## Шаги (порядок важен)

1. **Регистрация.** bitrix24.ru -> «Создать бесплатно» -> название «Запас хода».
   Это аккаунт владельца, Алиса в него не заходит (правило безопасности).
2. **Входящий вебхук.** CRM -> Настройки -> Вебхуки -> «Добавить вебхук» -> входящий ->
   права: CRM -> скопировать URL ЦЕЛИКОМ (до конца токена).
3. **Ключ в GAS.** Apps Script -> Настройки проекта -> Script Properties ->
   добавить свойство: B24_WEBHOOK_URL = <URL из шага 2>.
4. **Дельта v18.** Вставить содержимое reports/gas_v18_b24_sync.gs в конец Code.gs,
   сохранить.
5. **Тест.** Запустить функцию demoB24Sync() -> в CRM появится лид
   «ТЕСТ — B24-интеграция» -> удалить его из CRM.
6. **Воронка (2 минуты).** CRM -> Сделки (или Лиды) -> Настройки воронки ->
   стадии: Заявка / Связались / Прайс отправлен / Пилот / Сделка.
7. **Перенос существующих лидов (19 шт из листа «Лиды»).**
   Google-таблица -> Файл -> Скачать -> CSV -> Битрикс24 CRM -> Импорт -> лиды ->
   сопоставить колонки: ФИО, телефон, комментарий. Алиса может подготовить CSV
   по формату, если пришлёт лист.

## Подключение дельты к обработчикам
После вставки v18 в конец Code.gs добавить вызов в конце блока записи заявки
в лист B2B_Менеджеров (1 строка):
  zapB24Notify({source:'b2b_onboarding', title:'B2B: '+salon+' — '+name,
    comments:'QR-ID: '+(startId||'прямой')+'; Город: '+city+'; TG: @'+tg,
    phone:'', tg:'@'+tg});
Готовые вызовы для запроса прайса и расчёта проекта (b2b_price / b2b_project):
  zapB24Notify({source:'b2b_price', title:'Оптовый прайс: '+company+' — '+name,
    comments: comment, phone: phone, tg:''});
  zapB24Notify({source:'b2b_project', title:'Проект: '+company+' — '+name,
    comments: comment, phone: phone, tg:''});

## Что делает Алиса после твоего теста
- сверит поступление первого реального лида (буклет) в CRM;
- если вебхук падает — диагностика по журналу GAS (пришлёшь журнал).
