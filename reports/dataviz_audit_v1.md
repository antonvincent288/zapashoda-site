4. KPI-ряд: tabular-nums, CAPS-заголовки — по канону.

## 10 конкретных улучшений (приоритет по эффекту)
1. Плитка погоды → статус «кабины» (P0): крупно +1°, под ней «запас ~186 км (−25%)». Отвечает на вопрос «доехать-вернуться можно?».
2. Прогноз-маркер на графике (P0, из референса AI Smart Restock): пунктирная оранжевая вертикаль «заправка ~N дней».
3. Не фрагментировать выбор: три режима карты держать на одной доске (сегменты, уже сделано — сохранить).
4. Дельты KPI — только реальные: нет истории → не рисовать «▲ 12%»; вместо этого контекст «из 3129».
5. Сетка графика 5-8% opacity, оси без рамок; tooltip — приподнятая поверхность #161C28, hairline, ≤3 строк.
6. Цвет дозировать: оранжевый только на данных и CTA; не более 1 оранжевого элемента на плитку (кроме главной линии графика).
7. Столбики по разъёмам: CCS2 599 — оранжевый, остальные приглушённо-синие/серые (не чередовать оранж/синий).
8. Таблица городов: сортировка по совместимости %, hover оранж .05 (есть); без zebra.
9. Мобильная доска: плитки в 2 колонки (цифры 22px), карта 52vh, список bottom-sheet, тач-таргеты ≥ 44px.
10. 5-секундный тест после волны E: «сколько станций? в моём городе? доехать могу?» — если не считывается, упрощать.

## Что НЕ делать (анти-паттерны)
Гейджи-спидометры без данных, радары, 3D, глоу на тексте, фейковые тренды-спарклайны, >5 цветов, дубли легенд. Pure black/white — запрещены (halation): фон #0A0E15, текст #EDF2F9 — держать.

## Порядок волн (подтверждён)
B: плитка погоды (п.1) + контекст-дельты (п.4). C: график с прогноз-маркером (п.2) + сетка/tooltip (п.5). D: workflow-схема «Как это работает» (Flowforge-паттерн). E: таблица по % (п.8) + 5-секундный тест.

## Измеримость
- Время до первого ответа доски (сек) на 3 вопроса.
- Доля плиток с «действием» ≥ 70%.
- Контраст-аудит WCAG по ключевым поверхностям.
